# Azure Infrastructure Automation Using Terraform

## Overview

This project demonstrates the basics of provisioning and managing Microsoft Azure infrastructure using **Terraform** and **Infrastructure as Code (IaC)** principles.

The project uses Terraform configuration files to create and manage an Azure Resource Group and demonstrates the basic Terraform infrastructure lifecycle, including initialization, planning, deployment, modification, and destruction of resources.

## Objectives

- Learn the fundamentals of Terraform and Infrastructure as Code.
- Provision Azure infrastructure using Terraform.
- Understand Terraform configuration files and Azure providers.
- Use Terraform variables to create flexible configurations.
- Understand Terraform state and output values.
- Practice the basic Terraform infrastructure lifecycle.

## Technologies Used

- Microsoft Azure
- Terraform
- Infrastructure as Code (IaC)
- Azure Resource Group
